# 首次设置与参数收集

只在配置不存在或本次请求缺少关键资料时读取本文件。不要为了填满配置而阻塞一堂课的备课。

## 首次使用

一次询问以下必要默认值；允许用户回答“每次再说”：

1. 常教科目与级别；
2. 一节课通常多少分钟；
3. 常用教案语言与文件格式；
4. 是否常用校本简略教案模板；
5. 是否常做教学简报，以及偏好可编辑、快速或视觉型；
6. 默认输出目录；
7. 是否允许把课文上传至 NotebookLM 等第三方服务。

把答案复制为 `teacher-profile.yml`，放在用户选择的位置。不要擅自保存学校、班级或个人资料。

## 每次任务的最低资料

- 科目、年级/班级程度、课题；
- 本次课时长度及节数；
- 教师提供的课文/讲义；
- 本次要的产物；
- 有日期或周次要求时的准确锚点；
- 简略教案需要写入时的原始模板；
- 简报需要生成时的路线或结果偏好。

先从当前消息、附件和配置推断。缺少多个必要参数时一次问齐；不影响主要内容的字段可写“待教师填写”。

## 不应成为通用默认值的项目

- 35、40 或 45 分钟；
- J1/J2/J3 或 S1/S2/S3；
- 某一科目；
- 固定周次、星期或班级；
- 某所学校的路径、文件名或 Excel 行号；
- Q版、写实或任何固定简报风格；
- NotebookLM、某一图像模型或某个 MCP。

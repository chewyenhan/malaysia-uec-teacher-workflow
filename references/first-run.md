# 首次设置与参数收集

从本次消息、附件和已保存的教师配置提取资料，缺失且会影响结果时一次问齐。允许“每次再说”；不为填写配置而阻塞备课。

## 一次性确定本课

| 参数 | 如何确定 |
|---|---|
| 科目、年级／学生程度、课题 | 优先读取教师请求及材料 |
| 课时与节数 | 使用教师指定值，不预设 35／40／45 分钟 |
| 教材及教学范围 | 教师提供文件／文字；核对章节边界 |
| 课程路线 | 统考要求选 `uec`；其他课程选 `custom`；学校名称不代替课程体系 |
| 自定义课程依据 | 教师指定标准、文件／公开网址，或明确“仅依据教材及教学目标” |
| 交付范围 | 默认详细教案＋逐页讲稿＋PPT 大纲＋真实 PPTX；只有教师明确限定才缩减；简略教案与额外评量可选 |
| 课件偏好 | 必须介绍 NotebookLM MCP `notebooklm` 与 AI 生图整页 `imagegen` 两种视觉课件方案；教师要求可编辑文字时提供 `editable`；仅大纲 `outline-only` 只在教师明确选择时使用。询问必要的风格／页数 |
| 简略教案模板 | 需要写入时才要求；不凭学校名称猜单元格 |
| 周次／日期 | 要求周次时核对教师给的日期块；不从今天日期自行换算 |
| 输出目录 | 使用教师选择；没有时用当前目录的课题子目录 |

班级人数等不影响设计的缺项可写“待教师填写”。已知答案、已选路线不要重复问。

## 首次自定义课程设置

用户第一次选择 `custom`，且还没有可复用的自定义课程配置时，先用一轮简短设置把课程依据和稳定偏好定下来。不要把每课内容当成长期设置；只问会影响后续备课的项目：

1. **课程与标准**：课程／课程标准名称；依据是教师提供的文件或网址、教师自订目标，还是仅以本课教材为准。没有官方大纲时明确记作“未核对外部考纲”，不能猜一个国家课程来代替。
2. **常用教学范围**：默认科目、年级／学生程度、课时。教师可逐课覆盖，不把未给出的周次或日期推算出来。
3. **教学与评量偏好**：例如语言、活动方式、常用评量、班级模板；只记录教师实际提供且以后会复用的内容。
4. **PPT 偏好**：优先问 NotebookLM MCP 或 AI 生图整页；若教师明确需要可逐字编辑的文字框，再选 `editable`。记录风格、常用比例或页数时只保存其明确偏好。
5. **保存范围**：请教师选“只用于本课”或“保存为这个课程以后默认设置”。选保存时先展示将保存的项目与目标文件位置，得到确认后才创建／更新配置；不保存账号密码、学生资料或未获授权的课文副本。

设置完成后，在后续任务沿用这些默认值，只询问本课变化项；不能因为资料已保存就推断第三方上传授权，也不能把 `custom` 自动改为 UEC。不同课程可有不同配置，避免把数学课偏好套到另一门课。

## 可选教师配置

见 [teacher-profile.example.yml](../teacher-profile.example.yml)。只有教师希望保存默认值时才写入其指定位置。只保存需要的设置，不要求学校或个人资料。

- `teaching.curriculum_route`：`uec` 或 `custom`；配置未填写时本次确定。
- `teaching.curriculum`：实际课程体系名称；自定义课程不冒用 UEC。
- `teaching.custom_standards`：指定文件／公开网址，或教材依据。
- `teaching.custom_course_profile`：教师确认保存的课程标准名称、依据说明、常用教学偏好与评量偏好；不保存私人账号信息。
- `outputs.slides.preferred_route`：课件路线，与课程路线独立；支持 `auto`、`editable`、`notebooklm`、`imagegen`、`outline-only`。
- 来源副本、第三方上传与工具安装按教师实际选择处理。

旧版只有 `curriculum: Dong Zong / UEC` 的配置可识别为 `uec`；其他值按实际课程判断，有歧义才确认。旧 `preferred_route: auto` 保留为“按结果与工具能力选择”，不自动同意上传。

## 首次使用示例

**独中统考适配**

> 我教初二历史，一节 40 分钟。按这份课文备课并核对统考考纲。需要详细教案、学校模板的简略版、写实课件和讲稿；课件选 NotebookLM。

**自定义课程**

> 我第一次用这个工作流，走自定义课程。我教五年级数学，30 分钟，主题是同分母分数加法。按我提供的材料和教学目标备课，不对照统考。请先一次问齐课程默认设置，并让我选择设置只用于本课还是保存。PPT 先介绍 NotebookLM MCP 和 AI 生图整页两种方案，让我选择。

对 NotebookLM，先提供 MCP 连接方式，再列明需要上传的教案、大纲、教材、讲稿；没有本课明确上传授权时只准备本地文件。没有选用 NotebookLM 的课程不检查 Google 登录或安装其依赖。选 AI 生图路线时先检查当前 Agent 的实际图像生成工具；没有可用工具时说明受阻，不假称已生成。

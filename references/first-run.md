# 首次设置与参数收集

从本次消息、附件和已保存的教师配置提取资料，缺失且会影响结果时一次问齐。允许“每次再说”；不为填写配置而阻塞备课。

## 一次性确定本课

| 参数 | 如何确定 |
|---|---|
| 科目、年级／学生程度、课题 | 优先读取教师请求及材料 |
| 课时与节数 | 使用教师指定值，不预设 35／40／45 分钟 |
| 教材及教学范围 | 教师提供文件／文字；核对章节边界 |
| 课程路线 | 统考要求选 `uec`；其他课程选 `custom`；学校名称不代替课程体系 |
| 自定义课程依据 | 教师指定标准、文件／公开网址，或明确“仅依据教材及教学目标” |
| 交付范围 | 教案、简略教案、大纲、讲稿、课件、评量按需组合 |
| 课件偏好 | 可编辑 `editable`、NotebookLM `notebooklm`、仅大纲讲稿 `outline-only`；同时询问必要的风格／页数 |
| 简略教案模板 | 需要写入时才要求；不凭学校名称猜单元格 |
| 周次／日期 | 要求周次时核对教师给的日期块；不从今天日期自行换算 |
| 输出目录 | 使用教师选择；没有时用当前目录的课题子目录 |

班级人数等不影响设计的缺项可写“待教师填写”。已知答案、已选路线不要重复问。

## 可选教师配置

见 [teacher-profile.example.yml](../teacher-profile.example.yml)。只有教师希望保存默认值时才写入其指定位置。只保存需要的设置，不要求学校或个人资料。

- `teaching.curriculum_route`：`uec` 或 `custom`；配置未填写时本次确定。
- `teaching.curriculum`：实际课程体系名称；自定义课程不冒用 UEC。
- `teaching.custom_standards`：指定文件／公开网址，或教材依据。
- `outputs.slides.preferred_route`：课件路线，与课程路线独立。
- 来源副本、第三方上传与工具安装按教师实际选择处理。

旧版只有 `curriculum: Dong Zong / UEC` 的配置可识别为 `uec`；其他值按实际课程判断，有歧义才确认。旧 `preferred_route: auto` 保留为“按结果与工具能力选择”，不自动同意上传。

## 首次使用示例

**独中统考适配**

> 我教初二历史，一节 40 分钟。按这份课文备课并核对统考考纲。需要详细教案、学校模板的简略版、写实课件和讲稿；课件选 NotebookLM。

**自定义课程**

> 我教五年级数学，30 分钟，主题是同分母分数加法。按我提供的材料及教学目标备课，不对照统考。要教案、可编辑课件、大纲和讲稿。

对 NotebookLM，先列明需要上传的教案、大纲、教材、讲稿，并沿用已有授权；只缺工具时说明可选配套仓库及安装范围。没有选用 NotebookLM 的课程不检查 Google 登录或安装其依赖。

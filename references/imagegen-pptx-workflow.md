# AI 生图整页 PPTX：跨 Agent 执行流程

本路线面向希望课件视觉完整、接近 NotebookLM 图像式页面的教师。它不绑定 Codex、Claude、Gemini 或某一家图像模型；执行者必须使用当前 AI Agent 环境真正提供、且能返回图像文件的生图工具。不能仅凭模型名称推断已具备生图能力。

## 能力检查与边界

1. 检查当前会话可用的图像生成工具及其调用、输出路径和授权说明。优先使用当前环境已连接的工具；不自行安装 Skill、插件、API 客户端或付费服务。
2. 确认工具可以生成并保存可用的图片文件。只有文本提示词、无法生成文件或输出无法取回时，标记此路线受阻，不能声称 PPTX 已生成。
3. 这条路线生成的是**每页一张完整画面**，再把图片放进真实 PPTX。标题、中文、数字和图表可能被绘入图片，通常不能像文本框一样逐字修改。必须向教师说明此限制。
4. 生图服务可能按次收费或有额度限制。费用不明时先核实工具说明；需额外付费、启用新服务或上传资料时遵守当前 Agent 与教师授权要求。

## 逐页生产

1. 先完成教案、稳定编号的大纲和逐页讲稿；大纲是结构蓝本，教材和已核实课程材料才是事实依据。执行 [PPT 同步关卡](ppt-synchronization.md) 的来源与编号要求。
2. 读取 [完整 PPT 风格库](slide-style-library.md)，建立全片视觉规范：目标年级、比例、字体气质、色板、插画／摄影方式、页面留白、图标和角色一致性。为图像工具准备视觉描述，不把版式要求误当作教材事实。
3. 每页先写一份独立画面规格，至少列出页面编号、准确标题、必须显示的原文、构图、主要图像、图表关系、禁止内容与来源。提示词应将“画面描述”和“必须准确呈现的文字”分开；不让工具自行补充史实、课程标准、公式答案或来源。
4. 先生成一页代表样张，检查画风、文字可读性、主题准确度和教学适切性。向教师展示样张并取得确认，再批量生成；本次已经确认过的同一风格可沿用。
5. 按页面逐张生成，不用一张大图切页。文件以 `P01.png`、`P02.png` 等命名并记录实际输出位置、工具名称（仅限工具明确提供）和生成状态。若工具不保证精确文字渲染，避免把长段讲稿塞进图片；只保留短标题和必要标签，在讲稿中提供完整讲解。
6. 用现有且可验证的 PPTX 工具把每张图按比例置入一页幻灯片，保持顺序、边界和清晰度。不要假称图片画面中的文字可编辑；教师如果要求可编辑文字，改走 `editable` 路线并先确认。

每页提示词可以按下列结构写，再依当前生图工具的格式调整：

```text
为教师制作一张 16:9 横向教学幻灯片图片，仅生成这一页，不要拼成多页海报。
页面编号：P01
学生程度与页面教学目的：{年级；这一页要让学生学会／观察什么}
视觉规范：{选定风格、色彩、构图、留白、角色一致性}
画面主体：{具体场景、物件、地图或图表关系}
必须呈现的短文字（照录，不增删）：
标题：{准确标题}
标签：{必要的短标签；没有则写“无”}
事实来源：{教师材料文件名与位置；画面内容不得超出来源}
不要加入额外文字、装饰性假字、来源中没有的史实或未经核实的数字。
输出一张可用于幻灯片的清晰图片文件。
```

如果所用图像模型无法稳定照录文字，改为不含文字的画面底图，并用已有、可验证的 PPTX 工具叠加真实文本框；在任务记录中说明本页采用混合制作，不把图像文字说成可编辑。

## 验收与失败恢复

- 检查真实 PPTX 页数与大纲一致，图像尺寸与比例正确，没有空页、错序、缺图或拉伸。
- 逐页打开或渲染实际 PPTX，检查图中文字是否完整、清晰、无错字和乱码，内容是否符合教材、讲稿与学生程度；地图、数字、公式、专名要重点人工核对。
- 如果图中文字错误，优先减少图中文字并重生成该页，或使用已验证的编辑工具覆盖短标签。修正时同步大纲、讲稿和教案页码；完成后重新验收关联页面。
- 在验收记录注明“图片式 PPTX，页面文字主要为图像内容”，写明实际通过数、修正页和待核项。无法打开渲染时只能报告结构检查，不能声称视觉检查完成。
- 中断后沿用已生成的页面与任务记录，只补生成缺失或确认失败的页面；不要不经检查重做全部页面。
- 生图能力、保存能力或组装工具缺失时，保留已完成材料，标明阻塞环节和下一步。不得静默切换到 NotebookLM、editable 或 outline-only。

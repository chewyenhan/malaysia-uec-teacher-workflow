# 课件路线、大纲与讲稿

课程体系（UEC／自定义）与课件工具是两个独立选择。两种课程都可选以下任一路线。

## 按结果选择

| 路线 | 适合需求 | 必须说明 |
|---|---|---|
| `editable` | 真文字、图形、公式可继续修改 | 当前工具能否实际生成、打开与检查 PPTX |
| `notebooklm` | 用教师来源生成统一视觉课件 | 上传范围、登录、实际格式及可编辑程度 |
| `outline-only` | 教师明确只需大纲讲稿 | 哪些已完成，哪些课件步骤未执行 |

缺失才同轮确认投影／自学用途、课时、必要页数、风格、编辑需求及费用偏好。教师指定路线时沿用；不可用则说明缺口，不静默更换已选路线。

原生简报工具优先满足精确中文、公式、图表和可编辑需求。图片可以做视觉素材，不把本应可编辑的文字画进图片。特殊视觉路线先做一页代表样张，确认后再批量制作。

NotebookLM 的工具来源与完整步骤见 [notebooklm-workflow.md](notebooklm-workflow.md)。已有可用浏览器或接口就复用，不强制安装 MCP。

AI Agent 直接生成 PPTX 必须按 [agent-pptx-workflow.md](agent-pptx-workflow.md) 执行：逐页规格 → 样张 → 批量组装 → 页序与讲稿对账 → 逐页渲染验收。

## 同一页面贯穿大纲与讲稿

每页采用稳定标识 `P01`、`P02` 等，标题可改，标识用于交叉核对。大纲最小字段：

| 页面编号 | 页面目的 | 标题 | 核心内容 | 教师动作／提问 | 学生活动 | 视觉或媒体建议 | 来源 |
|---|---|---|---|---|---|---|---|

页数按课时、活动和内容密度决定，不固定某页必须分隔。每页明确一种视觉处理，避免只有“写实／Q版”而没有实际构图说明。

讲稿按 `## P01 页面标题` 排列，包含讲解、课堂提问及参考答案、过渡或操作提示，并对应学生任务。自然口语不等于随意补史实；讲稿中的事实和数字仍须有来源。

## 生成后的实际检查

- 按实际页序逐页核对目标、标题、事实、数字、专有名词与公式。
- 打开或渲染，确认投影可读、没有遮挡、缺图、错字或误导性画面。
- 检查大纲、讲稿和最终课件是否对应；生成服务可能改变页数或合并内容，不能只检查计划页数。
- 图片式课件明确标为“文字烘焙在图片中”；真正编辑过文字与图形后才宣称可编辑。
- 问题页单独修正，复查关联讲稿与文件；详见 [quality-and-resume.md](quality-and-resume.md)。

未生成课件时交付已完成教案、大纲和讲稿，明确 PPTX 尚未完成及原因，保留所选路线与继续步骤；不能将完整任务改称 outline-only 或宣称完成。不生成伪装格式或空白 PPTX。

## 页面与讲稿的固定最低要求

大纲必须写总体教学目标、已确认的视觉基调及逐页编号。每页除现有表格字段，还须注明页面角色、对应教学目标／课程条目、预计分钟数及具体构图。角色应覆盖导入、核心学习、练习／形成性检查、总结与课末检查；可合并页面，但不得省掉教学功能。每页一个核心主题，低年级通常不超过3条短要点，高年级通常不超过5条；必要公式、史料或表格按教学用途调整，不能为字数上限删掉关键内容。

每页教师讲稿使用以下模板，不能只写“介绍本页／按PPT讲解”：

```markdown
## P01 {与大纲一致的标题}
- 对应目标与预计用时：{实际值}
### 可直接讲授的讲解
{自然口语、基于教材的完整讲解}
### 提问／学生任务
{具体问题或任务；无提问的过渡页说明用途}
### 参考答案与反馈
{答案要点、常见误解、提示与补教}
### 操作及过渡
{指图／板书／活动操作与连接下一页的话}
### 来源与教师提醒
{位置、课程重点或待核项}
```

讲稿时间与活动时间合计符合课时，避免一页数百字却只分配半分钟。最终课件改了页序或内容须同步三份材料。视觉风格缺失时提供 Q版、故事绘本、写实、手绘、水墨、科技霓虹（也可自定义简洁教学风）供教师选择；推荐须适应年级与学科，不能默默决定。AI 生图路线先展示样张并取得教师确认，再批量制作；沿用本次已有样张批准。普通排版样张可按实际授权由 Agent 自检。

生成后和后续修改时必须执行 [PPT同步关卡](ppt-synchronization.md)，保存逐页映射及四份成品摘要；最终验收不得跳过。

选择风格和制作前必须读取 [完整PPT风格库](slide-style-library.md)；将所选风格落实到每页构图、配色和文字布局，并以样张检查全片一致性。

# 教材读取与内容清单

## 原则

教师提供什么，就忠实读取什么。教材正文只是材料的一部分；表格、图像、公式、资料框和练习往往决定课堂活动，不能省略。

## 按格式读取

### DOCX

按文档顺序交错读取段落与表格，不要只使用 `document.paragraphs`。记录标题层级、页眉页脚中有教学意义的内容、表格结构、内嵌图片及相邻图注。必要时可运行：

```bash
python scripts/inspect_docx.py path/to/material.docx
```

### PDF

检查总页数、目录、目标页范围、可选择文字、表格、图片和页下注。扫描型 PDF 需要 OCR，但 OCR 后仍要回看页面，确认表格列关系、上下标、符号及图注。

### 图片或扫描页

逐张记录页码/顺序、正文、版面区域、表格、图表、公式、图片说明及被裁切内容。低清晰度导致无法辨认时列出具体位置，请教师补图，不猜字。

### 电子表格

读取所有相关工作表、合并单元格、公式、隐藏行列、数据验证、打印范围和样例行。先判断模板结构，再决定写入位置。

## 内容清单格式

```markdown
| 类别 | 数量 | 位置 | 标题/摘要 | 教学用途或注意事项 |
|---|---:|---|---|---|
| 正文 |  |  |  |  |
| 表格 |  |  |  |  |
| 图片与图注 |  |  |  |  |
| 地图/图表/时间线 |  |  |  |  |
| 公式/符号 |  |  |  |  |
| 资料框/史料 |  |  |  |  |
| 例题/练习/活动 |  |  |  |  |
```

表格另附完整的行列内容；图像另写“看得见什么、图注说什么、正文如何引用它”。不存在的类别写“未发现”。

## 边界与核对

- 以相邻章节标题、页码、书签或样式核实目标章节起止。
- 抽查开头、末段、标题数、表格数、图片数及总页数/字数。
- 课文表述与一般知识冲突时，保留原文并提示教师核对，不静默改写。
- 生成内容必须能追溯到课文、教师补充资料或明确标注的外部来源。

# 版权、署名与隐私

本文件提供项目操作边界，不构成法律意见。

## 教材

- 教师自行提供其合法取得且有权处理的课文、讲义、图片和模板。
- 不从网络寻找或下载未经授权的课本、教师手册、扫描页、题库或付费资料。
- 不把“教学用途”当成可以公开上传、重新分发或收入 GitHub 的自动许可。
- 成品需要引用短段落或教材图表时，只取课堂所需范围，并保留来源；公开分享前由教师再次检查权利。

## 教师与学生资料

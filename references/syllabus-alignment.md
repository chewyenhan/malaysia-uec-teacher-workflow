# 董总／统考考纲对照

## 来源策略

优先使用本机已同步的官方文件。缓存不存在或版本不明时，运行：

```bash
python scripts/sync_uec_syllabi.py --level all
```

官方入口记录在 [`official-sources.json`](official-sources.json)。仓库不内置考纲 PDF，以避免版本过期及重新分发问题。

## 对照步骤

1. 确认初中/高中、科目、考试年份或版本；
2. 在官方文件中定位相关章节、学习范围、能力要求及题型说明；
3. 抄录准确编号与短标题，并记录文件名和页码；
4. 把“考纲明确要求”与“教师为了理解而补充”分开；
5. 依据考纲深度调整目标和评量，不把考纲变成课文目录。

## 建议输出

```markdown
| 课文知识/能力 | 考纲原文或编号 | 文件与页码 | 本课处理 | 状态 |
|---|---|---|---|---|
|  |  |  | 教授/复习/延伸 | 已核实/待核 |
```

## 无法核实时

- 不凭记忆填写编号、题型比例或“高频考点”。
- 先完成严格依据教师材料的教学设计。
- 把缺失项目集中列在“待教师核对”，附官方入口。
- 官方站恢复后再补齐，不改用来历不明的转载文件。

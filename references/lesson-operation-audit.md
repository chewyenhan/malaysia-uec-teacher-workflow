# 课堂操作、材料配套与独立终审

对本次授权交付范围执行；教师只要单份教案时不强制生成 PPT。凡设计中实际要求发放、投影或填写的配套材料，均须提供可使用的最终文件。课时、科目、课程体系及输出路线以本课设置为准。

## 一、把操作写进教学过程

每项活动在详细教案的分时教学过程内按序号写清，不把关键步骤只放在附录、讲稿或交付后的聊天里：

1. 先讲解／示范还是先探索，说明何时转入活动；依教学目的选择先后。
2. 何时发哪份材料、每人／组几份、打开哪一页；哪些题现在做、哪些保留为独立课末检查。正常路线使用已制作的练习单；白纸或黑板替代仅作为明确的备用方案。
3. 教师可照读的口令、完整问题、PPT 页面编号、练习单题号与答题格。
4. 学生先独立做什么、写／说／操作什么、在哪里完成、用时多久及留下的个人证据。
5. 合作活动的分工、先后轮次、谁检查、按什么标准、意见不同时如何处理。只写“同桌讨论／互评”不合格。
6. 教师何时巡视、抽答、提供答案、记录结果、反馈和订正；附参考答案／表现规准和常见错误的具体处理。
7. 如何收取、总结与衔接下一步。发材料、合作、检查、补教等用时均计入教师指定课时；多节课逐节核对。

## 二、按用途设计评量并落实操作

不要把“课前、课中、课末”三个时点当成三类评量：

- **诊断性检查**：确认先备知识、误解或困难，以决定教学起点或支架；也可在课中进行。
- **形成性评量**：收集学习证据，反馈、订正并调整下一步教学；不能只有活动而没有判断及后续行动。
- **总结性评量**：在一个单元、课程或阶段结束后评定学习成果及目标达成程度，依真实课程／学校安排实施。

阶段性描述时间安排。课末、独立作答、计分都不自动等于总结性。八分课末题若用于找错、补教和再检查，主要为形成性用途；确有双重用途时分别说明反馈和成果评定的用法。

每个评量点在教学过程对应行列出：评量 ID、用途与目标、完整题面／任务、材料及题号／格位、师生步骤与时间、个人证据、记录方式、答案／达标标准、未达标时的反馈补教、再检查时点与具体任务，以及达标者的延伸或下一步。不得只写“观察学生表现”。口答可记录目标达标情况，不必为每个动作计分。

每课在评量设计中说明“总结性评量安排／衔接”：本课承担时写范围、目标、题目／任务、评分规准、实施收取及结果用途，并纳入本课过程和时间；不承担时说明理由与可衔接的单元／阶段目标和范围。日期、权重未知标待确认，不强塞考试、不编造成绩或已发生的教学结果。

## 三、逐任务核对材料与答题格

建立 `activity-alignment.md`，每个要求学生回答或操作的任务一行，包含讲稿举例、PPT 题、课堂练习、课末检查和作业：

| 活动 ID／目标 | 分钟／教学先后 | 教案／讲稿／PPT位置 | 口答／书写／操作 | 材料题号／答题格名称及数量 | 答案／达标标准 | 个人证据与记录 | 评量用途／反馈补教／再检查 |
|---|---|---|---|---|---|---|---|

所有书写任务必须有实际且足量的答题空间。分别写两种做法须有两格；短横线不能代替长答区。写定义、举例、配对或理由都要有位置，或在所有材料中一致改为口答。不得教案要求写、练习单却无格，交付后再口头改活动。

实际打开／渲染练习单的最终打印件，检查格数、用途和书写空间；口答／操作明确无需书面格。课末独立检查不能提前填写同一格充作课堂练习。答案只在教师版／备注，不能泄漏到学生练习画面。

列全本课材料清单，含练习单、卡片、史料、图表、地图、操作单及作业等实际文件和最终打印／展示版；不适用明确注明。未要求书面作答时不为凑文件生成空白练习单。

## 四、由独立 agent 全量终审

全部最终文件形成后，实际派一名未参与编写的 agent 读取：本次范围内的最终教案、讲稿、大纲、PPTX 或逐页渲染图、练习单源文与最终打印件、全部实际另发材料、对照表、本规则，以及相关原始教材和适用课程／评量依据。提供来源版本、页码／章节及可读取原件，不给作者的“已通过”判断。

要求全量核对每项活动和评量，不能随机抽查：

- 操作是否可照做，教学先后、发材料、个人任务、合作轮次、纠错、收取与时间是否完整。
- 各文件题面、题号、时机、方式、答案是否一致；每项书写均有足量实际格位。
- 每项目标有个人证据、记录和达标线；评量按用途分类，反馈补教和再检查直接写入教学过程；总结性安排／衔接合理。
- 内容与任务逐项对照原教材、适用科目／年级／版本的考纲或课程标准；评量与教师指定或适用的教学规范对应，标出原文和教案位置。
- 区分官方要求、学校安排和本工作流加强项。UEC 路线核对适用董总原件；其他学科／年级的文件仅可作概念参考。custom 路线用教师指定依据，不强加董总要求。

教师明确没有外部标准时，以教材和已确认目标为范围，标“未核对外部考纲”，不假装认证课程。应有但无法取得的依据记未核实；可继续制作并交付已有成果，但对应依据及总体终审不能记为通过，也不能宣称符合该规范。

将结果写入 `independent-audit.md`：agent 标识、实际读取文件及版本／SHA-256、逐活动结论、问题位置、来源依据、修复要求与复审结果。分别报告“材料与操作配套”“课程／规范依据”“评量设计与实施步骤”。这里审核的是计划可执行性，不能冒称观察到真实课堂实施。

失败项修正所有关联文件，更新打印／渲染件，再交同一 agent 复审。通过后修改任务、题面或作答方式须重新核对并复审；仅改 hash 不算复审。没有独立 agent 工具时明确标“独立终审未完成”，保留作者自查，不能冒称通过。

最终包包含实际使用的配套文件、`activity-alignment.md` 与 `independent-audit.md`；在 `qa-report.md` 和任务记录中写审核版本、agent、分项状态和复审结论。单份短教案可沿用简短记录，但仍须记录独立终审结果。离线结构检查通过不证明这项内容审核通过。
